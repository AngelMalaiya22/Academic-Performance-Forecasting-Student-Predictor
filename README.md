# Student Success Predictor (Streamlit)

Academic Performance Forecasting & Student Success Predictor - predicts a student's final grade (0-20)
and at-risk probability (G3 < 10), in two modes: early warning (no grades) and mid-term (G1/G2 known).

Run locally:
    pip install -r requirements.txt
    streamlit run app.py
